# Max Bot

Простая реализация бота для Max Messenger на языке Go.

## Возможности

- Отправка и получение сообщений на русском языке
- Базовая обработка команд (приветствие, помощь, время, эхо)
- Поддержка групповых чатов с хранением сообщений по чатам для последующего анализа
- Специальные команды администратора для указанного пользователя (+79310071775)
- Правильная обработка упоминаний бота в групповых чатах
- Корректная обработка завершения работы
- Конфигурация через переменные окружения
- Анализ сообщений в отслеживаемом чате с помощью AI (OpenRouter) для выявления информации о больничных и отпусках

## Требования

- Go 1.16 или выше
- Токен бота Max Messenger
- GitHub CLI (для синхронизации с GitHub)

## Установка

1. Клонируйте или скачайте этот репозиторий
2. Установите зависимости:

```bash
go mod tidy
```

3. Создайте файл .env в корне проекта с вашим токеном:
```
MAX_BOT_TOKEN=ваш_токен_бота_здесь
```

Примечание: Шаблон файла .env предоставляется в виде .env.example, который можно скопировать и изменить.

## Как запустить

### Локальный запуск:
1. Убедитесь, что вы создали файл .env с `MAX_BOT_TOKEN`
2. Запустите бота:

```bash
go run main.go
```

### Запуск в Docker:
1. Убедитесь, что у вас установлены Docker и Docker Compose
2. Убедитесь, что файл .env содержит `MAX_BOT_TOKEN`
3. Запустите бота:

```bash
docker-compose up -d
```

Бот запустится и начнет прослушивание сообщений.

## Конфигурация

Бот использует следующие переменные окружения:

- `MAX_BOT_TOKEN`: Ваш токен бота Max Messenger (обязательно)
- `ADMIN_USER_ID`: ID пользователя, которому будут доступны административные команды (необязательно, по умолчанию 0)
- `ADMIN_CHAT_ID`: ID чата администратора для получения уведомлений об анализе сообщений (необязательно)
- `CHAT_ID`: ID чата для отслеживания и анализа сообщений с помощью AI (необязательно)
- `OPENROUTER_API_KEY`: Ключ API для доступа к сервису OpenRouter (обязательно, если используется анализ сообщений)
- `OPENROUTER_MODEL`: Модель OpenRouter для анализа (необязательно, по умолчанию arcee-ai/trinity-large-preview:free)

## Поддерживаемые команды

### Для всех пользователей (в личных сообщениях):
- `/help`: Получить список доступных команд
- `/echo [text]`: Повторить за пользователем текст

### Для администратора (пользователь с ID, указанным в переменной окружения ADMIN_USER_ID) (в личных сообщениях):
- `/help`: Получить список всех команд (включая администраторские)
- `/echo [text]`: Повторить за пользователем текст
- `/last`: Получить последние сохраненные сообщения из текущего чата
- `/stat`: Получить статистику сохраненных сообщений с группировкой по чатам

### Поведение в групповом чате:
- Когда бота упоминают (с помощью "@bot" или "/"), отвечает "Извините, я пока не умею разговаривать."
- Все сообщения в групповых чатах сохраняются по чатам для последующего анализа
- Бот не отвечает на другие сообщения в групповых чатах, кроме случаев упоминания

## Расширение возможностей бота

Чтобы добавить новую функциональность:

1. Измените `handlers/handler.go`, чтобы добавить новые обработчики команд
2. Обновите функцию `Handle`, чтобы распознавать новые команды
3. Добавьте необходимые вспомогательные функции
