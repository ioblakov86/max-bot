# Max Bot - Инструкциональный документ

## Обзор проекта

Max Bot - это простая реализация бота для Max Messenger на языке Go. Проект предназначен для автоматизации взаимодействия в корпоративных чатах, особенно для отслеживания информации о больничных и отпусках сотрудников с использованием искусственного интеллекта.

### Основные возможности:
- Отправка и получение сообщений на русском языке
- Базовая обработка команд (приветствие, помощь, время, эхо)
- Поддержка групповых чатов с хранением сообщений по чатам для последующего анализа
- Специальные команды администратора для указанного пользователя (+79310071775)
- Правильная обработка упоминаний бота в групповых чатах
- Корректная обработка завершения работы
- Конфигурация через переменные окружения
- Анализ сообщений в отслеживаемом чате с помощью AI (OpenRouter) для выявления информации о больничных и отпусках

Проект использует следующие основные зависимости:

- `github.com/rs/zerolog` - логирование

## Конфигурация

Бот использует следующие переменные окружения:

- `MAX_BOT_TOKEN`: Ваш токен бота Max Messenger (обязательно)
- `ADMIN_USER_ID`: ID пользователя, которому будут доступны административные команды (необязательно, по умолчанию 0)
- `ADMIN_CHAT_ID`: ID чата администратора для получения уведомлений об анализе сообщений (необязательно)
- `CHAT_ID`: ID чата для отслеживания и анализа сообщений с помощью AI (необязательно)
- `OPENROUTER_API_KEY`: Ключ API для доступа к сервису OpenRouter (обязательно, если используется анализ сообщений)
- `OPENROUTER_MODEL`: Модель OpenRouter для анализа (необязательно, по умолчанию arcee-ai/trinity-large-preview:free)

## Команды бота

### Для всех пользователей (в личных сообщениях):
- `/help`: Получить список доступных команд
- `/echo [text]`: Повторить за пользователем текст

### Для администратора (пользователь с ID, указанным в переменной окружения ADMIN_USER_ID) (в личных сообщениях):
- `/help`: Получить список всех команд (включая администраторские)
- `/echo [text]`: Повторить за пользователем текст
- `/last`: Получить последние сохраненные сообщения из текущего чата
- `/stat`: Получить статистику сохраненных сообщений с группировкой по чатам

### Поведение в групповом чате:
- Когда бота упоминают (с помощью "@bot" или "/"), отвечает "Извините, я пока не умею разговаривать."
- Все сообщения в групповых чатах сохраняются по чатам для последующего анализа
- Бот не отвечает на другие сообщения в групповых чатах, кроме случаев упоминания

## Система AI анализа

Бот может анализировать сообщения в указанном чате (через переменную `CHAT_ID`) с помощью AI для выявления информации о больничных и отпусках сотрудников. Анализ происходит с использованием OpenRouter API и следующего процесса:

1. Сообщения из отслеживаемого чата отправляются в OpenRouter API
2. Используется промпт из файла `prompt.txt` для инструкций модели
3. Результат анализируется и извлекаются следующие данные:
   - Тип отсутствия (больничный или отпуск)
   - Должность сотрудника
   - ФИО сотрудника
   - Даты начала и окончания
   - Статус (начало, окончание)
   - Замещающий сотрудник (если указан)

Результаты анализа отправляются администратору в виде форматированного сообщения с клавиатурой для принятия решения.

## Структура данных

### MessageAnalysis
Структура, представляющая результат анализа сообщения:
```go
type MessageAnalysis struct {
    OriginalMessage string `json:"original_message"`
    IsValid         bool   `json:"is_valid"`
    Employee        struct {
        Position  string `json:"position"`
        FullName  string `json:"full_name"`
    } `json:"employee"`
    AbsenceType string `json:"absence_type"`
    Dates       struct {
        StartDate string `json:"start_date"`
        EndDate   string `json:"end_date"`
    } `json:"dates"`
    Status     string `json:"status"`
    Substitute string `json:"substitute"`
}
```

## Сборка и запуск

### Локальный запуск:
1. Убедитесь, что у вас установлен Go 1.16 или выше
2. Установите зависимости:
```bash
go mod tidy
```

3. Создайте файл .env в корне проекта с вашими настройками:
```
MAX_BOT_TOKEN=ваш_токен_бота_здесь
ADMIN_USER_ID=79310071775
CHAT_ID=идентификатор_чата_для_анализа
OPENROUTER_API_KEY=ваш_ключ_api_openrouter
```

4. Запустите бота:
```bash
go run main.go
```

### Запуск в Docker:
1. Убедитесь, что у вас установлены Docker и Docker Compose
2. Убедитесь, что файл .env содержит все необходимые переменные
3. Запустите бота:
```bash
docker-compose up -d
```

## Разработка

### Добавление новых команд:
1. Измените `handlers/handler.go`, чтобы добавить новые обработчики команд
2. Обновите функцию `Handle`, чтобы распознавать новые команды
3. Добавьте необходимые вспомогательные функции

### Расширение AI анализа:
1. Измените промпт в файле `prompt.txt` для изменения поведения AI
2. При необходимости обновите структуру `MessageAnalysis` в `ai/openrouter.go`
3. Настройте логику обработки результатов в методе `analyzeMessageWithAI` в `handlers/handler.go`

## Обработка сигналов и завершение работы

Бот корректно обрабатывает сигналы SIGINT и SIGTERM для безопасного завершения работы. При получении сигнала завершения:
1. Отменяется контекст выполнения
2. Завершаются все активные горутины
3. Приложение завершается с логированием события

## Хранение сообщений

Сообщения хранятся в памяти с использованием структуры `MessageStorage`, которая обеспечивает:
- Безопасный доступ из нескольких горутин с помощью мьютексов
- Хранение сообщений по ID чатов
- Возможность получения истории сообщений для конкретного чата
- Получение статистики по всем чатам
