# Max Bot - Инструкциональный документ

## Обзор проекта

Max Bot - это бот для Max Messenger на языке Go, предназначенный для автоматизации взаимодействия в корпоративных чатах. Основная функция - отслеживание информации о больничных и отпусках сотрудников с использованием AI (OpenRouter) для анализа сообщений.

### Основные возможности:
- Отправка и получение сообщений на русском языке
- Базовая обработка команд (/help, /echo)
- Поддержка групповых чатов с хранением сообщений
- Специальные команды администратора (/last, /stat)
- Обработка упоминаний бота в групповых чатах
- Анализ сообщений с помощью AI для выявления информации об отсутствии сотрудников
- Отправка сообщений с inline-кнопками для подтверждения действий

## Команды бота

### Для всех пользователей (в личных сообщениях):
- `/help` - Показать список доступных команд
- `/echo [text]` - Повторить текст за пользователем

### Для администратора (ADMIN_USER_ID):
- `/help` - Показать все команды (включая администраторские)
- `/echo [text]` - Повторить текст
- `/last` - Последние 5 сохранённых сообщений из текущего чата
- `/stat` - Статистика сообщений по всем чатам

### Поведение в групповом чате:
- При упоминании (@bot или /) отвечает: "Извините, я пока не умею разговаривать."
- Все сообщения сохраняются для последующего анализа
- На другие сообщения не реагирует

## AI анализ сообщений

Бот анализирует сообщения из отслеживаемого чата (CHAT_ID) на предмет информации об отсутствии сотрудников:

1. Сообщение отправляется в OpenRouter API с промптом из `prompt.txt`
2. AI извлекает структурированные данные:
   - Тип отсутствия (Больничный/Отпуск)
   - Должность и ФИО сотрудника
   - Даты начала и окончания
   - Статус (Начало/Окончание/Продолжение)
3. При валидном результате отправляется уведомление администратору с кнопками "Принять"/"Отмена"

### Структура MessageAnalysis:
```go
type MessageAnalysis struct {
    OriginalMessage string
    IsValid         bool
    Employee        struct {
        Position  string
        FullName  string
    }
    AbsenceType string
    Dates       struct {
        StartDate string
        EndDate   string
    }
    Status     string
    Substitute string
}
```

## Сборка и запуск

### Локальный запуск:

Сообщения хранятся в памяти в структуре `MessageStorage`:
- Потокобезопасный доступ через sync.RWMutex
- Хранение по ID чатов
- Методы для получения истории и статистики

## API Max Messenger

### Отправка сообщений:
- **URL**: `https://platform-api.max.ru/messages`
- **Метод**: POST
- **Параметры**: `chat_id` (query parameter)
- **Заголовок**: `Authorization: <token>`

### Формат сообщения с клавиатурой:
```json
{
  "text": "Сообщение",
  "attachments": [
    {
      "type": "inline_keyboard",
      "payload": {
        "buttons": [
          [
            {
              "type": "callback",
              "text": "Кнопка",
              "payload": "action"
            }
          ]
        ]
      }
    }
  ]
}
```

### Известные ограничения API:
- ❌ Редактирование сообщений не поддерживается (PUT /messages/{id} возвращает 404)
- ❌ Удаление клавиатуры после нажатия кнопки невозможно
- ❌ Callback answer через POST /messages/callback не поддерживается (возвращает 404)

## Разработка

### Добавление новых команд:
1. Откройте `handlers/handler.go`
2. Добавьте обработку команды в `handlePrivateMessage` или `handleAdminCommands`
3. Обновите справку `/help`

### Расширение AI анализа:
1. Измените промпт в `prompt.txt`
2. При необходимости обновите `MessageAnalysis` в `ai/openrouter.go`
3. Настройте логику обработки в `analyzeMessageWithAI`

### Стиль кода:
- Стандартный стиль Go (gofmt)
- Обработка ошибок обязательна
- Использование контекста для управления жизненным циклом
- Логирование через стандартную библиотеку `log`

## Структура данных обновлений

Бот обрабатывает следующие типы обновлений:
- `TypeMessageCreated` - создание нового сообщения
- `TypeMessageCallback` - нажатие на inline-кнопку

```go
type MessageCallbackUpdate struct {
    Callback Callback  // Содержит callback_id, payload, user
    Message  *Message  // Оригинальное сообщение с клавиатурой
}
```
